# Estudos Java

Repositório destinado ao registro da minha evolução no estudo da linguagem Java.

Aqui estão exercícios, experimentos, implementações e pequenos projetos
desenvolvidos durante meu aprendizado (ou um monte de bits sequenciais para tentar representar alguma coisa).
O código não tem como objetivo representar aplicações de produção.
Este é um ambiente de prática: erros, refatorações e mais erros fazem parte do processo.

## Conteúdos

- Fundamentos
- Programação Orientada a Objetos
- Interfaces
- Herança e Polimorfismo
- Collections
- Exceptions
- Generics
- Lambdas
- Streams
- Java I/O
- Testes

## Objetivo

Construir uma base sólida em Java através de prática constante, documentando minha evolução ao longo do tempo.

## Observação

Digo e repito: este repositório representa meu processo de aprendizado. Portanto, é esperado encontrar código simples, experimentos e implementações, erros de sintaxe, erros de lógica, enfim, erros e mais erros, a fim de, um dia, transformá-los em acertos.
